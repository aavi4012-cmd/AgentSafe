# Security Policy

AgentSafe is an open-source AI safety MVP. Please do not share private credentials, tokens, or production data in issues or pull requests.

## Reporting a vulnerability

If you discover a security issue, please email the maintainer privately rather than opening a public issue.

Please include:

- a summary of the issue
- affected component
- reproduction steps
- suspected impact
- suggested mitigation

## Supported versions

This project is currently in MVP stage and is maintained on the `main` branch.
